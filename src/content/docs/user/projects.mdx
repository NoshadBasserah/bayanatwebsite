## Steps to Create a New Project

<div class="docs-step-list">
  <GuideStepCard
    number={1}
    title="Navigate to the Projects tab"
    description="Open the Projects section from the left navigation sidebar."
  />
  <GuideStepCard
    number={2}
    title="Click on the (+) Add button to create a new Project"
    description="Click the + Add button at the top of the project list to open the project creation form."
  />
  <GuideStepCard
    number={3}
    title="Enter the Required Details"
    description="Fill in the project Name (required), Display Name, and a Description to explain the project's purpose."
  />
  <GuideStepCard
    number={4}
    title="Configure Visual Identity"
    description="Set an icon URL to represent the project visually, and choose a Color that will appear as a visual indicator throughout the UI."
  />
  <GuideStepCard
    number={5}
    title="Add Tags &amp; Glossary Terms"
    description="Optionally attach Tags and Glossary Terms to the project to group related governance metadata under a unified structure."
  />
  <GuideStepCard
    number={6}
    title="Click Save"
    description="Confirm the project creation. The new project will appear in the list immediately."
  />
</div>

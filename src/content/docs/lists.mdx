<GuideIntro  image={listintro}>
  <h1>Lists</h1>
  <p>
    Lists allow administrators to create and manage curated collections of data
    assets.
  </p>
  <p>
    These collections can be used for organizing assets by project,
    department, data domain, or any custom grouping criteria. Lists help users
    discover related assets and maintain logical groupings.
  </p>
</GuideIntro>

## Additional Information

<GuideCallout title="Additional Information" variant="info">
  <p>
    Lists can be shared with specific users or teams, or made publicly
    accessible to all platform users.
  </p>
  <p>
    Membership is dynamic, so when an asset is removed from the platform it is
    automatically removed from any lists that reference it. Users can also
    subscribe to lists to receive notifications when assets are added or
    removed.
  </p>
</GuideCallout>

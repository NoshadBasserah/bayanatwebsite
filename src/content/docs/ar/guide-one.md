## نظرة عامة

هذا دليل توضيحي. استخدمه للتحقق من التباعد وأنماط النثر وسلوك التنقل أثناء بناء المحتوى الخاص بك.

> **تلميح:** يتم عرض الاقتباسات بنمط مميز. استخدمها للإشعارات.

## جدول

| الحقل | النوع | الوصف |
|-------|------|-------------|
| `id` | `string` | معرف فريد. |
| `name` | `string` | اسم العرض. |
| `active` | `boolean` | ما إذا كان السجل نشطاً. |

## مثال على الكود

```ts
interface User {
  id: string;
  name: string;
  active: boolean;
}

function greet(user: User): string {
  return `مرحباً، ${user.name}`;
}
```

## قائمة

1. الخطوة الأولى.
2. الخطوة الثانية.
3. الخطوة الثالثة.

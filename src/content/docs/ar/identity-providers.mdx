<GuideIntro>
  <h1>موفرو الهوية</h1>
  <p>
    يدعم BayanatiHub تسجيل الدخول الموحد للمؤسسات (SSO) من خلال التكامل
    مع موفري الهوية الخارجيين.
  </p>
  <p>
    يمكن للمسؤولين تهيئة موفري الهوية مثل Active Directory (AD)
    وخدمات Active Directory Federation Services (ADFS). يتيح ذلك المصادقة
    الآمنة وإدارة الوصول المركزية وتجربة تسجيل دخول سلسة عبر المنصة.
  </p>
</GuideIntro>

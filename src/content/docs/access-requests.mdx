  <h1>Access Requests</h1>
  <p>Users can request access when:</p>
## Conditions for Access Request Approval
<ul class="list-disc marker:!text-primary-600 pl-5">
<li> A dataset is published but not assigned to them.</li>
<li> A dashboard exists but requires permission.</li>
<li> They need additional privileges, such as adding members to a space or assigning licenses.</li>
</ul>
</GuideIntro>

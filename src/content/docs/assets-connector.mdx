## Steps to Connect a Data Source

<div class="docs-step-list">
  <GuideStepCard
    number={1}
    title="Navigate to the Assets Connector tab"
    description="Open the connector workspace to review existing integrations, their status, and recent sync activity."
    image={stepOne}
    imageAlt="Assets connector landing page"
  />
  <GuideStepCard
    number={2}
    title="Click Add New Connector"
    description="Start a new connection setup by creating a connector record for the external system you want to integrate."
    image={stepTwo}
    imageAlt="Add new connector action"
  />
  <GuideStepCard
    number={3}
    title="Select the connector type from the available options"
    description="Choose the source category that matches your integration, such as a database, dashboard, metadata source, or pipeline tool."
    image={stepThree}
    imageAlt="Connector type selection options"
  />
  <GuideStepCard
    number={4}
    title="Enter the connection details"
    description="Provide the hostname, port, database or workspace name, authentication method, and credentials required by the selected service."
    image={stepFour}
    imageAlt="Connector details form"
  />
  <GuideStepCard
    number={5}
    title="Test the connection before saving"
    description="Validate credentials and network reachability so the system can confirm the source is accessible."
    image={stepFive}
    imageAlt="Connection test result"
  />
  <GuideStepCard
    number={6}
    title="Configure metadata extraction settings"
    description="Define which schemas, catalogs, tables, folders, or filters should be included when metadata is ingested."
    image={stepSix}
    imageAlt="Metadata extraction settings"
  />
  <GuideStepCard
    number={7}
    title="Set the extraction schedule"
    description="Choose how often the connector should sync metadata, such as hourly, daily, or weekly."
    image={stepSeven}
    imageAlt="Extraction scheduling options"
  />
  <GuideStepCard
    number={8}
    title="Save and activate the connector"
    description="Once enabled, the connector becomes available for metadata imports and scheduled synchronization."
    image={stepEight}
    imageAlt="Save and activate connector"
  />
</div>
